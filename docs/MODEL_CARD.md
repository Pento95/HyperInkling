# Inkling 2 Mini, INT4 GPTQ experts, for one RTX 3090 / 3090 Ti

A requantization of [thinkingmachines/Inkling-2-Mini](https://huggingface.co/thinkingmachines/Inkling-2-Mini)
(Apache-2.0) that fits a 24 GB Ampere card, made for and served by
[HyperInkling](https://github.com/Pento95/HyperInkling): a pinned vLLM with one patch, a launcher and a setup
wizard. **It needs that patch to load**; stock vLLM does not know the expert format.

> A personal project, published because it may help other 3090 owners. One RTX 3090 or
> 3090 Ti only: no other GPU generation, no multi-GPU, no support promise.

## What changed against the release

| part | release | here |
|---|---|---|
| routed experts, layers 0-19 | NVFP4 | **INT4, group 128, asymmetric, GPTQ-calibrated** (AWQ packing, for Marlin) |
| routed experts, layers 20-23 | MXFP8 | same INT4 GPTQ |
| attention, LM head, token embeddings | bf16 | bf16 here; HyperInkling makes them INT8 g128 at load time |
| vision tower and projector | bf16 | bf16, unchanged |
| DSpark drafter (`mtp.safetensors`) | bf16 | bf16, unchanged; HyperInkling makes its layers INT4 at load |
| routers, norms, loop controllers, small tensors | as released | unchanged |

17 GB on disk instead of ~20. There is no bf16 master of the experts: GPTQ ran on the
dequantized NVFP4/MXFP8 weights, so the reference is the release itself.

Calibration: 166k tokens from public datasets (NousResearch/hermes-function-calling-v1,
pixparse/docvqa-single-page-questions, ise-uiuc/Magicoder-Evol-Instruct-110K,
wikimedia/wikipedia 20231101.it, HuggingFaceH4/ultrachat_200k), with the answers generated by
the original checkpoint, MoE inputs and routing captured from it, then GPTQ per expert. A
second round of 166k tokens changed nothing measurable. The pipeline is in HyperInkling's
`prepare/`.

## Quality

Teacher-forced KL against the original checkpoint on 22 held-out transcripts (images, tool
calls, code, Italian, chat), one request at a time. Compare medians: a few positions where
a small difference flips an expert dominate the mean.

| | KL median | KL mean | top-1 agreement |
|---|---|---|---|
| the original against itself | 0 | 0 | 100% |
| INT4 round-to-nearest experts (older build) | 0.0039 | 0.133 | 91.2% |
| **INT4 GPTQ experts (this checkpoint)** | **0.0030** | **0.117** | **92.5%** |
| + INT8 attention, head, embeddings, FP8 KV (HyperInkling's defaults) | 0.0031 | 0.123 | 92.1% |

Task accuracy, the same server settings for both (`bench/quality_battery.py`, greedy, 200
items each; about +-1 to +-3 points of noise):

| | original checkpoint | this checkpoint, served by HyperInkling |
|---|---|---|
| GSM8K | 0.970 | 0.970 |
| tool calls, exact (names only) | 0.645 (0.735) | 0.615 (0.710) |
| DocVQA as strict JSON, ANLS (valid JSON) | 0.938 (99.5%) | 0.935 (99.5%) |

## Sampling

Temperature 1.0 is the default here, as in the base model. The base model's card reports long
reasoning loops: cap `max_tokens` and the agent's turns.

## Speed with HyperInkling (RTX 3090 Ti)

RTX 3090 Ti undervolted to 350 W with [gpu-unlock](https://github.com/zagitta/gpu-unlock)
active (it raises prefill, not decode); HyperInkling's defaults (KV cache FP8 E4M3, prefill
chunk 2048, async scheduling). Prompts of exactly 8k or 32k tokens, 512 tokens out, greedy;
decode measured on prefix-cache hits while every request generates, so no prefill is inside
it. "Aggregate" is the sum over the requests running at once.

| | 1 request, no DSpark | 1 request, DSpark | 6 requests, no DSpark | 6 requests, DSpark |
|---|---|---|---|---|
| prefill, per request, 8k context | 6,283 tok/s | 6,191 tok/s | 2,292 tok/s | 2,417 tok/s |
| prefill, aggregate, 8k context | 6,283 tok/s | 6,191 tok/s | 6,243 tok/s | 6,191 tok/s |
| decode, per request, 8k context | 131 tok/s | 267 tok/s | 68 tok/s | 114 tok/s |
| decode, aggregate, 8k context | 131 tok/s | 267 tok/s | **407 tok/s** | **686 tok/s** |
| prefill, per request, 32k context | 5,255 tok/s | 5,209 tok/s | 2,123 tok/s | 2,114 tok/s |
| prefill, aggregate, 32k context | 5,255 tok/s | 5,209 tok/s | 5,267 tok/s | 5,223 tok/s |
| decode, per request, 32k context | 124 tok/s | 188 tok/s | 58 tok/s | 108 tok/s |
| decode, aggregate, 32k context | 124 tok/s | 188 tok/s | **350 tok/s** | **646 tok/s** |

## Maximum context with HyperInkling (RTX 3090 Ti)

Longest single request, 8 requests served at once, KV cache FP8 E4M3 (8 bits), fitted by the
server at boot.

| vision tower | DSpark (default) | no DSpark |
|---|---|---|
| on the GPU (default) | **340k** | 431k |
| in host RAM | 375k | 471k |
| none (text only) | 377k | 473k |

Async scheduling off gives ~17k more, a 1024-token prefill chunk ~12k more. Without DSpark and
the vision tower, async off, chunk 1024: 500k.

## Use

```bash
git clone https://github.com/Pento95/HyperInkling hyperinkling && cd hyperinkling
python3 scripts/wizard.py && docker compose up -d   # downloads this checkpoint
```

The server is OpenAI-compatible (`/v1`, model `inkling-2-mini`), with tool calls
(`--tool-call-parser inkling`), reasoning (`--reasoning-parser inkling`) and images.
