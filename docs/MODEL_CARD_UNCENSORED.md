# Inkling 2 Mini Uncensored, INT4 GPTQ experts, for one RTX 3090 / 3090 Ti

A requantization of [OpenUncensored/Inkling-2-Mini-Uncensored](https://huggingface.co/OpenUncensored/Inkling-2-Mini-Uncensored)
(Apache-2.0: [Inkling 2 Mini](https://huggingface.co/thinkingmachines/Inkling-2-Mini) with its
refusals removed by abliteration; only the 20 attention output projections are edited) that
fits a 24 GB Ampere card, made for and served by
[HyperInkling](https://github.com/Pento95/HyperInkling). **It needs HyperInkling's patch to load**;
stock vLLM does not know the expert format. The same recipe as
[Pentium95/Inkling-2-Mini-W4A16-g128-gptq](https://huggingface.co/Pentium95/Inkling-2-Mini-W4A16-g128-gptq),
calibrated on this model's own text.

> A personal project, published because it may help other 3090 owners. One RTX 3090 or
> 3090 Ti only: no other GPU generation, no multi-GPU, no support promise.

## What changed against the source

| part | source | here |
|---|---|---|
| routed experts, layers 0-19 | NVFP4 | **INT4, group 128, asymmetric, GPTQ-calibrated** (AWQ packing, for Marlin) |
| routed experts, layers 20-23 | MXFP8 | same INT4 GPTQ |
| attention (with the abliterated output projections), LM head, token embeddings | bf16 | bf16 here; HyperInkling makes them INT8 g128 at load time |
| vision tower, DSpark drafter, routers, norms, loop controllers | as in the source | unchanged |

17 GB on disk instead of ~20. GPTQ ran on the dequantized NVFP4/MXFP8 weights, so the
reference is the source itself.

Calibration: 338k tokens in two rounds from public datasets
(NousResearch/hermes-function-calling-v1, pixparse/docvqa-single-page-questions,
ise-uiuc/Magicoder-Evol-Instruct-110K, wikimedia/wikipedia 20231101.it,
HuggingFaceH4/ultrachat_200k), with the answers generated by the uncensored model itself, MoE
inputs and routing captured from it, then GPTQ per expert (HyperInkling's `prepare/`).

## Quality

Teacher-forced KL against the source on 22 held-out transcripts (images, tool calls, code,
Italian, chat), one request at a time. Compare medians: a few positions where a small difference
flips an expert dominate the mean. Measured before the server was repeatable (0.0003 / 0.060 of noise).

| | KL median | KL mean | top-1 agreement |
|---|---|---|---|
| **INT4 GPTQ experts (this checkpoint)** | **0.0025** | **0.111** | **92.8%** |
| + INT8 attention, head, embeddings, FP8 KV (HyperInkling's defaults) | 0.0027 | 0.115 | 92.6% |

One calibration round (166k tokens) gave 0.0026: doubling it changed nothing measurable.

## Sampling

Temperature 1.0 is the default here, as in the base model. The base model's card reports long
reasoning loops: cap `max_tokens` and the agent's turns.

## Speed and context

The same as the original checkpoint served by HyperInkling (same architecture, sizes and
kernels): see [its card](https://huggingface.co/Pentium95/Inkling-2-Mini-W4A16-g128-gptq) and
HyperInkling's README. ~340k tokens of context with DSpark, 8 requests and the vision tower on
the GPU.

## Use

```bash
git clone https://github.com/Pento95/HyperInkling hyperinkling && cd hyperinkling
python3 scripts/wizard.py && docker compose up -d   # answer b) to the first question
```

The server is OpenAI-compatible (`/v1`, model `inkling-2-mini`), with tool calls
(`--tool-call-parser inkling`), reasoning (`--reasoning-parser inkling`) and images.
